# CraneLoadingSystem 异地部署说明

> 适用于：v1.0.0 | 最新修复：全局复位 + 鹤位报警展开 + 报警行间距优化（commit 719c0c0）

---

## 📦 三个发布包怎么选？

| 包 | 异地机器要求 | 体积 | 启动方式 |
|---|---|---|---|
| `*-src.zip` 源码包 | 装 **.NET 10 SDK** | ~2 MB | 双击【启动.bat】（自动还原+编译+运行） |
| `*-fdd.zip` 框架依赖包 | 装 **.NET 10 Desktop Runtime x64** | ~20 MB | 双击【启动.bat】→ 直接运行 `app\CraneLoadingSystem.exe` |
| `*-selfcontained.zip` 自包含包 | **无 .NET 要求**（裸机也行） | ~150 MB | 双击【启动.bat】→ 直接运行 `app\CraneLoadingSystem.exe` |

### 快速选型
- ✅ 异地**完全没装** .NET → 选自包含包
- ✅ 异地只装了 **.NET 10 Runtime** → 选框架依赖包（体积小）
- ✅ 异地装了 **.NET 10 SDK** 且可能需要二次改代码 → 选源码包

## 🚀 三步部署（任意方案通用）

### 第一步：拷贝 + 解压
把选中的 ZIP 用 U 盘 / 内网共享 / 邮件拷贝到异地机器，**右键 → 全部解压** 到任意目录（建议放在非系统盘避免写权限问题，如 `D:\CraneLoadingSystem\`）。

> ⚠ **不要直接在 ZIP 里双击 exe**，一定先解压到磁盘目录再运行。

### 第二步：双击【启动.bat】

| 方案 | 启动后自动做什么 |
|---|---|
| 源码包 | 还原 NuGet → 编译 Release → 启动应用 |
| 框架依赖包 | 检查 .NET Runtime → 启动 CraneLoadingSystem.exe |
| 自包含包 | 启动 CraneLoadingSystem.exe |

### 第三步：验证画面出现
```
4 张鹤位卡片 → 全显示、状态=待机
PLC 灯 → 绿色（仿真模式自动连接）
SAP/ERP 灯 → 黄色或绿色（仿真模式有数据）
日志 → 不出现红色 Error
```

## 🔧 常见问题速查

### ❌ 启动 .bat 一闪而过 / 闪退
1. 在同目录空白处按住 `Shift` 右键 → **在此处打开终端** / **在此处打开 PowerShell 窗口**
2. 输入：`cmd /c 启动.bat`（或 PowerShell 下 `.\启动.bat`）
3. 会停留在窗口内显示完整错误，**把红色错误拍下来或复制出来** → 发给维护人员即可定位。

### ❌ 源码包：NuGet 还原 401 / 407
公司内网代理。CMD 执行下面两行再重新双击启动.bat：
```bat
set HTTP_PROXY=http://你的代理服务器:端口
set HTTPS_PROXY=http://你的代理服务器:端口
```

### ❌ 框架依赖包：启动闪退
异地缺少 .NET 10 Desktop Runtime x64。浏览器访问下载安装：
```
https://dotnet.microsoft.com/download/dotnet/10.0
→ 下载 Run desktop apps 栏下的 x64（Download .NET 10 Desktop Runtime x64）
```

### ❌ 自包含包：启动闪退
Windows Server 常见原因：没装**桌面体验** / 缺 VC++ Redistributable。
- **VC++**：https://aka.ms/vs/17/release/vc_redist.x64.exe 下载安装
- **Windows Server 桌面体验**：服务器管理器 → 添加角色和功能 → 功能 → 用户界面和基础结构 → 勾选【桌面体验】

### ❌ 鹤位卡片不显示 / PLC 未连接
- 查看程序所在目录下 `logs\` 文件夹的今日日志（`log-YYYYMMDD.txt`）
- 搜索 `[CraneMgr] 初始化` 看是否有报错行

### ❌ 报警条还是叠字 / 功能按钮没反应
- 确认你手上的 ZIP 是 **v1.0.0 commit 719c0c0 之后** 打的包
- 解压根目录下打开【版本.txt】确认版本说明

## ✅ 快速 UAT 功能清单（部署后按顺序点一遍）

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 启动应用 | 4 张鹤位卡片全显示，状态=待机，PLC 灯=绿色 |
| 2 | 点【🔄 刷新SAP/ERP单据】| 待下发 Tab 出现仿真单据 |
| 3 | 双击单据 → 选鹤位 → 确定 | 对应鹤位状态变=就绪 |
| 4 | 鹤位点【▶ 启动】→ 弹窗选【是】| 状态=装料中，进度条涨 |
| 5 | 鹤位点【⚠ 急停】| 鹤位**下方红色报警条正常展开（多行不叠）** |
| 6 | 鹤位点【↻ 复位】| 鹤位清 0 → 待机，报警条消失 |
| 7 | 工具栏点【↻ 全局复位】| 所有鹤位**同时**清 0 回待机 |
| 8 | 工具栏点【⚠ 全局紧急停止】| 所有鹤位瞬间变紧急停止 |
| 9 | 再点【↻ 全局复位】| 全部强制清 0 回待机 |
